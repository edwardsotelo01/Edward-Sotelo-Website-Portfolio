## Part 2: Design

**1. What overall style will best represent you (minimalist, creative, professional, etc.)?**

My style will be simple and professional. The website will have headings that are clear, readable text, and spacing sufficient for organizing the content but not excessive.

**2. What color scheme will you use and why?**

The website will feature an off-white background, dark green font, and green accents. This will ensure uniformity and good contrast between the font and background colors. There will be only one color scheme for the website, without a dark mode.

**3. What fonts will you use for headings and body text?**

Arial font will be used for headings and body text, with Helvetica and a general sans-serif font as the second option. Bold headings will be used to differentiate from the main text.

**4. How will your design reflect your personality or field?**

The structure of the design will show my interest in programming and web development due to its structured nature and useful elements. I hope that people would pay attention to my content.

**5. What layout will your homepage follow?**

My homepage will be headed by links that navigate the page, my name, and an introduction. There will also be a button to access my projects, an overview of my areas of interest, skills, and a highlighted section on "Code Bricks."

**6. How will you organize project sections visually?**

On my Projects page, I will be highlighting Code Bricks. It will be presented using a project title, an image, a brief description of the project, and details about my role in the development of the project.

**7. Will the site be mobile-friendly? How will you ensure responsiveness?**

Yes, my website will be mobile-friendly. This means that I will be using CSS media queries to make sure the layout is suitable for small screen resolutions, while also using a menu button for navigation.

**8. What visual hierarchy will guide visitors?**

A major heading will be used at the start of each page. The smaller headings will help in organizing the sections, while buttons and hyperlinks will point visitors to critical information.

**9. How will consistency be maintained across pages?**

The same navigation bar, fonts, colors, and footer will be present on all four pages. A common CSS file will maintain consistency in the design of the entire website.

**10. How will accessibility be considered (contrast, font size, readability)?**

Accessible fonts, color contrast, and descriptive headers will be used. Focusable links and buttons will have visible focus indicators. A skip-to-content link and alternative text will be provided for the screenshot of the project.

**11. Will you use icons, images, or illustrations? Why?**

A screenshot of Code Bricks will be added to make users aware of what the project is. The use of visuals will be limited for simplicity’s sake on the website.

**12. What portfolio websites inspired your design?**

The reason why I haven't chosen any particular website to look at is that the design of my website should be quite simple and introduce myself, my skills, and my project.

## Part 3: Interactivity

**1. What interactive elements will your site include (navigation menus, buttons, forms)?**

The following elements will be included in my website: navigation links, a button for my Projects page, email and GitHub links, and also a link to go back to the top.

**2. Will your site include a contact form? How will it work?**

There will be no contact form on my website. Rather, there will be an email link on the Contact page that will open the user’s email client, along with a link to my GitHub page.

**3. What JavaScript features will you implement?**

I will use JavaScript to open and close the mobile navigation menu. Users can also exit the menu by pressing the Escape key. I will ensure that the script remains focused on this particular task only.

**4. How will users receive feedback from interactions?**

The menu will be shown or hidden when the button is clicked by users. There will be hover and focus styles for the links and buttons, and the navigation will show the current page.

**5. How does interactivity improve the user experience?**

Interactivity will aid users in navigating the website and getting information effortlessly. The mobile menu will ensure easy navigation for small-screen devices, while project and contact links will provide options for future actions.
