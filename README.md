## Part 2: Design

**1. What overall style will best represent you (minimalist, creative, professional, etc.)?**

I will use a simple, professional style. The website will have clear headings, readable text, and enough spacing to keep the pages organized without adding unnecessary features.

**2. What color scheme will you use and why?**

I will use an off-white background, dark green text, and green accents. These colors create a consistent appearance and provide a clear contrast between the text and background. The website will use one color scheme without dark mode.

**3. What fonts will you use for headings and body text?**

I will use Arial for headings and body text, with Helvetica and a general sans-serif font as alternatives. Larger, bold headings will help separate sections from the main text.

**4. How will your design reflect your personality or field?**

My design will reflect my interest in programming and web development through its clear organization and practical features. I want visitors to focus on my information and work.

**5. What layout will your homepage follow?**

My homepage will begin with navigation links, followed by my name and a short introduction. It will include a button leading to my projects, a brief overview of my interests and skills, and a featured section for Code Bricks. A footer will appear at the bottom.

**6. How will you organize project sections visually?**

My Projects page will focus on Code Bricks. I will organize it with a project title, a screenshot, a short description, and information about my contribution. Clear spacing and headings will make the information easy to follow.

**7. Will the site be mobile-friendly? How will you ensure responsiveness?**

Yes, my website will be mobile-friendly. I will use flexible layouts and CSS media queries to adjust the content for smaller screens. The navigation will use a menu button on mobile devices.

**8. What visual hierarchy will guide visitors?**

The largest heading will introduce each page. Smaller headings will organize the sections, and buttons or links will direct visitors to important content. This will help visitors understand where to look first.

**9. How will consistency be maintained across pages?**

I will use the same navigation, fonts, colors, and footer across all four pages. A shared CSS file will keep the styling consistent throughout the website.

**10. How will accessibility be considered (contrast, font size, readability)?**

I will use readable font sizes, clear color contrast, and descriptive headings. Links and buttons will have visible keyboard focus indicators. I will also include a skip-to-content link and descriptive alternative text for the project screenshot.

**11. Will you use icons, images, or illustrations? Why?**

I plan to include a screenshot of Code Bricks so visitors can see what the project looks like. I will keep other visuals limited so the website remains simple and focused.

**12. What portfolio websites inspired your design?**

I have not selected a specific portfolio website as inspiration. My design focuses on a straightforward layout that introduces me, presents my skills, and showcases my project.

## Part 3: Interactivity

**1. What interactive elements will your site include (navigation menus, buttons, forms)?**

My website will include navigation links, a mobile menu button, a button leading to my Projects page, and email and GitHub links. It will also include a back-to-top link.

**2. Will your site include a contact form? How will it work?**

My website will not include a contact form. Instead, the Contact page will include an email link that opens the visitor’s configured email application and a link to my GitHub profile.

**3. What JavaScript features will you implement?**

I will use JavaScript to open and close the mobile navigation menu. Visitors will also be able to close the menu by pressing the Escape key. I will keep the JavaScript focused on this feature.

**4. How will users receive feedback from interactions?**

The mobile menu will appear or disappear when visitors click its button. Links and buttons will have visible hover or keyboard focus styles, and the navigation will indicate the current page.

**5. How does interactivity improve the user experience?**

Interactivity will help visitors navigate the website and find information easily. The mobile menu will make navigation more convenient on smaller screens, while project and contact links will give visitors clear next steps.
